# Как помочь с переводом

Спасибо, что хотите улучшить русскую локализацию DSH. Здесь коротко: как устроены
файлы, как переводить и как проверить результат.

## Файлы

- `en/<namespace>.json` — английские строки, извлечённые из приложения. **Не
  редактируйте вручную**: обновляются командой
  `node tools/extract.mjs "<путь к>/resources/app.asar"`.
- `ru/<namespace>.json` — перевод. Один файл на namespace, плоский объект
  «ключ → строка». Ключи и их порядок должны совпадать с `en/`.
- `lib/client.js` — собранный бандл. Генерируется `npm run build`, не правьте руками.

## Правила

1. **Плейсхолдеры** (`{name}`, `{count}`, `{value}`) переносите дословно; порядок слов
   можно менять по правилам русского языка.
2. **Не переводите**: `DeepSeek`, `DSH`, `GitHub`, `MCP`, `JSON`, `API`, `HTTP`,
   названия моделей, пути и имена файлов, кодовые идентификаторы, сочетания клавиш,
   имена продуктов (Cursor, VS Code, PDF).
3. **Стиль**: кратко и нейтрально, без обращений «вы»; кнопки — инфинитив
   («Сохранить»), заголовки — с заглавной буквы, короткие подписи — без точки.
4. **Типографика**: сохраняйте `…`, `—`, `·`, обрамляющие пробелы и регистр первой
   буквы. Кавычки — «ёлочки».
5. **Плюрализация**: ICU-форм в DSH нет, поэтому строки с `{count}` формулируйте
   нейтрально: «Файлов: {count}», «Ещё {count}» вместо «{count} файлов».

Глоссарий (держите единым по всем namespace):

| English | Русский |
|---|---|
| agent / subagent | агент / субагент |
| session | сессия |
| workspace | рабочая область |
| turn / step | ход / шаг |
| tool / skill | инструмент / навык |
| plugin / preset / profile | плагин / пресет / профиль |
| permission / approval | разрешение / подтверждение |
| sandbox | песочница |
| job (background) | задача |
| goal / plan | цель / план |
| schedule | расписание |
| attachment / deliverable | вложение / результат |
| compaction | сжатие контекста |
| sidebar | боковая панель |
| shortcut | сочетание клавиш |

## Проверка

```bash
npm run check   # build + проверка активации бандла
```

Сборка падает, если:

- для namespace нет файла перевода или в нём не хватает/лишние ключи;
- набор `{плейсхолдеров}` не совпадает с английским;
- значение пустое, хотя английское — нет.

CI дополнительно проверяет, что закоммиченный `lib/client.js` соответствует
`en/` и `ru/` (иначе `npm run build` даст дифф).

## Добавление нового языка

Пакет рассчитан на русский, но структура универсальна: скопируйте `ru/` в `xx/`,
поменяйте `LANGUAGE` в `tools/build.mjs` и имя пакета. Пулл-реквесты с другими
языками лучше оформлять отдельным репозиторием.
